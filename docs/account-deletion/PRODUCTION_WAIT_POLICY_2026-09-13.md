# 운영 탈퇴 대기 기간 결정 — 2026-09-13

운영자 요청에 따라 신규 탈퇴 요청의 자동 실행 대기 기간을 7일(168시간)로 정한다. 이는 운영자 결정이며 법적 적합성 확인을 의미하지 않는다.

- 설정: ACCOUNT_ERASURE_WAIT_HOURS=168. 코드 기본값 0의 미설정 차단은 유지한다.
- 접수 시각부터 정확히 168시간 후 자동 처리 대상이 된다. 영업일 또는 자정 기준이 아니다.
- 화면에는 서버의 scheduledAt을 표시한다. 예정 시각은 삭제 완료 시각이 아니다.
- 실제 실행 전까지 신청 취소 가능. 기존 관리자 조기 실행 기능은 유지한다.
- 나중에 환경값을 변경하고 서비스를 재시작하면 신규 요청에 적용한다. 이미 접수한 요청의 예정 시각은 자동 변경하지 않는다.
- 실제 활성화는 소셜 연결 해제 등 별도 운영 준비 상태와 구분한다.

## 적용 및 검증

- 운영 systemd override `98-erasure-wait.conf`에 168시간을 적용하고 재시작한 프로세스 환경에서 확인했다. 서버 health 응답 정상. 접수·워커는 기존 중지 상태를 유지했다.
- 격리 MariaDB 통합 테스트에서 168시간 예약, 기존 예약 보존, 예약 시각 경계와 관리자 조기 실행 검증 통과.
- 이번 설정 변경만으로 새 예약/취소 코드의 운영 배포나 기능 활성화가 완료된 것은 아니다.
