## 3. 공개 및 외부 서비스

동문 검색과 프로필 정보는 승인된 동문에게 제공하며 전화번호·이메일은 각각의 공개 설정에 따라 표시합니다 (`alumni_service.go`의 `publicValue`). 쪽지는 송수신자에게 제공되며, 신고한 메시지는 권한 있는 운영자가 검토합니다.

Apple 및 Kakao는 소셜 로그인에 사용됩니다. Apple 푸시 서비스는 앱 알림 전달에 사용됩니다. Sentry는 앱의 오류 및 성능 진단에 사용됩니다. 외부 기부 페이지는 별도 브라우저에서 열립니다.

서버 호스팅은 가비아 환경이며, 웹 글꼴은 Google Fonts와 jsDelivr에서 로드합니다. 일반 앱 문의에는 Gmail, 개인정보 요청에는 네이버 메일을 이용합니다. 장학회는 해피나눔에서 기부 내역을 받는다고 운영자가 확인했습니다. 현재 가져오기 코드는 이름·기수·학과·전화번호·금액 및 입력된 기부일자를 처리하지만, 실제 해피나눔 수신 항목과 전달 근거는 확인이 필요합니다. iOS Sentry DSN은 `ingest.us.sentry.io`로 연결되지만, 이 주소만으로 전체 저장 지역·국외 이전 조건을 확정하지 않습니다. 운영자는 Sentry 저장 지역·보관 기간과 서버 백업 보관 기간을 모른다고 답변했습니다 (2026-09-06).

## 4. 보관 기간과 삭제

새 릴리스에서 앱의 삭제 요청은 DB에 영구 접수되고 계정 이용을 중지합니다. 담당자는 통상 3일 내 삭제를 목표로 처리하고 10일 내 결과를 개별 안내합니다. 관리자 화면은 DB의 잔여 회원 참조와 이번 요청의 소셜 권한 철회 증빙을 검증한 후 완료할 수 있습니다. 실제 DB·파일·외부 서비스·백업 삭제는 담당자와 서버 관리자가 수행합니다. 운영 배포·실제 회원 삭제는 이 작업에서 실행하지 않았습니다.

일반 회원정보·사진·쪽지·인증정보는 목적이 끝나거나 삭제 요청이 있으면 지체 없이 파기합니다. 법정 자료는 필요한 필드만 별도 보관합니다. 기부자별 영수증 발급명세 5년(전자영수증 예외 검토), 해당 공익법인등 장부/중요 증빙 10년은 장학회와 해당 자료에 적용되는 의무를 확인한 뒤 사용합니다. 전체 회원 자료에 일괄 적용하지 않습니다.

완료 신고 자료는 최대 90일, 삭제 접수증은 완료 후 30일을 지나면 정리합니다. 불필요해진 신고 자료나 유효한 삭제 요청 대상은 더 일찍 삭제합니다. 방문 상세 기록의 기존 90일 정리, 만료 인증정보·전달 억제 메시지 정리도 유지합니다. 방문 쿠키는 발급일부터 1년입니다.

백업 7일 순환, Sentry 30일 이하는 실제 설정 확인 전의 목표이며 공개 페이지에서는 실제 기간 확인 중으로 표시합니다. 개인정보취급자 접근기록의 1년/해당 시 2년 의무는 별도 점검이 필요합니다. 구체적 절차는 `MANUAL_ACCOUNT_DELETION_RUNBOOK.md`, 근거와 적용 조건은 `PRIVACY_RETENTION_REVIEW.md`를 참고합니다.
