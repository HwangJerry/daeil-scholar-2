# 댓글 신고 운영 및 배포

2026-09-15. 댓글 신고는 로그인한 회원이 타인의 공개 댓글을 신고하는 기능이다.
동문 승인 여부만으로 접수를 막지 않는다. 신고 자체로 댓글을 숨기지 않는다.

- POST `/api/feed/{seq}/comments/{cSeq}/reports`: `reason`, `details`만 받으며 원문과 작성자는 서버가 조회한다. 같은 신고자는 같은 댓글에 대해 동일한 접수번호를 받는다.
- 관리자 `/comment-reports`: 원문·현재 공개 상태를 확인하고 필수 처리 사유와 확인 대화상자를 거쳐 숨김/기각한다. 숨김은 같은 댓글의 미처리 신고를 함께 종결한다.
- 신고 사유는 harassment/spam/inappropriate/other, 추가 설명은 Unicode 코드 포인트 1,000자까지다.
- 계정별 15분당 10회 요청을 허용한다. 현재 서버의 인메모리 제한이므로 재시작 시 초기화되고 여러 프로세스 간 공유되지 않는다.
- 같은 결과와 사유의 관리자 재전송은 성공, 다른 결과/사유는 409다. 작성자가 삭제한 댓글도 신고 당시 원문은 관리자에게 남는다.
- 기존 신고 자료 정책과 동일하게 완료 후 최대 90일, 관련 회원 탈퇴 시 더 먼저 삭제한다. 기존 보존 만료 작업 설정을 따르며 이 기능 때문에 만료 작업을 새로 활성화하지 않는다.
- 신고자/원문/추가 설명은 관리자 API만 반환한다. 일반 사용자에게는 접수번호와 received 상태만 반환한다.

배포: migration 070을 적용한 후 backend/admin, 이후 iOS/Android를 배포한다.
070은 추가 테이블만 생성하며 기존 댓글을 수정하지 않는다. 기존 WEO_BOARDBBS/WEO_BOARDCOMAND/WEO_MEMBER는 058 이후 InnoDB여야 한다.
백엔드 롤백 시 신고 테이블을 삭제하지 않는다. 앱 제출 전 해당 API와 관리자 접근을 확인한다.
운영 담당자는 기존 지원 페이지에 공지된 매일 확인/48시간 내 조치 목표로 관리자 목록을 확인한다.

검증은 합성 자료를 사용하는 MariaDB 10.1 통합 테스트, 앱 빌드·단위 테스트와 관리자 UI 테스트로 수행한다.
운영 회원 댓글을 테스트 목적으로 신고하거나 숨기지 않는다.
