# 개인정보처리방침 추가 확인 결과 — 2026-09-06

코드와 공식 공개 자료, 운영 서버의 제한된 설정 조회 결과다. 배포·서버 설정 변경·DB 조회·개인정보 원문 열람·삭제는 실행하지 않았다.

## 직접 확인한 사실

### 기부 가져오기 항목

`backend/internal/service/donation_import_service.go`의 엑셀 파서는 이름, 기수, 학과/부서, 전화번호, 금액을 읽는다. `backend/internal/model/donation_import.go`는 기부일자를 관리자가 배치 단위로 별도 입력한다고 명시한다. 회원 매칭 시 회원 번호를 연결한다.

공개 방침의 기부 정보 항목을 이 코드에서 처리하는 범위로 구체화했다. 샘플 파일을 반드시 받아야 할 이유는 없으므로 파일 제출 요청은 보류한다. 단, 엑셀 원본에 앱이 읽지 않는 추가 열이 있는지, 장학회가 원본을 별도 보관하는지, 제공 근거·계약상 역할은 코드만으로 확정하지 못했다.

### 공익단체 지정

행정안전부 게시물에 첨부된 **기획재정부 공고 제2025-131호** PDF를 직접 내려받아 텍스트와 표를 확인했다.

- 4쪽: 재지정 98개 단체의 인정기간 **2025.1.1. ~ 2030.12.31.**
- 7쪽: 재지정 목록 29번 **대일외국어고등학교장학회**, 사업목적 **장학사업 및 기타 공익활동 실시**.
- 공고의 근거는 **소득세법 시행령 제80조 제1항 제5호**다.

이는 해당 명칭의 단체가 그 공고에서 재지정되었다는 근거다. 법인세법상 공익법인 지정, 상증세법의 개별 장부 보존 의무, 실제 전자영수증 발급 여부까지 동일한 사실로 취급하지 않는다. 별도 취소·변경 여부나 단체의 법인세법상 취급까지 이 공고 하나로 확정하지 않는다.

기부금 발급명세 보관 규정에는 소득세법 제160조의3도 있으므로 공개 방침에 해당 법을 추가하고 적용 조건을 유지했다. 전자영수증 발급 여부는 여전히 공개 자료로 확인하지 못했다.

### Sentry

iOS `Sources/App/Infrastructure/Push/AppDelegate.swift`에서 Release의 충돌 수집, 성능 추적, 네트워크 추적이 활성화되고 trace 표본 비율은 1.0이다. `Config/Info.plist`의 DSN은 미국 수집 엔드포인트(`ingest.us.sentry.io`)를 사용한다.

이 코드에는 서버측 데이터 보관 기간 설정이 없다. 현재 연결된 도구에서 Sentry 전용 커넥터도 발견되지 않았다. DSN으로 조직/프로젝트 식별은 가능하지만 계약·제품별 보관 기간·전체 이전 국가를 확인하거나 관리 API를 인증할 수는 없다. 실제 Sentry 조직 설정/계약 확인이 남아 있다. 현재 단계에서 30일 보관 또는 개인정보 미수집을 시행 중이라고 추가 기재하지 않았다.

### 백업

`daeil-prod`에 기존 SSH 인증으로 접속하여 다음만 읽었다.

- systemd timer 목록의 backup/snapshot/dump/rotate 관련 항목: 발견하지 못함.
- `/etc/crontab`, `/etc/cron.d`, `/etc/cron.daily`, `/etc/cron.weekly`, `/etc/cron.monthly`, `/var/spool/cron` 아래 읽을 수 있는 예약 작업 파일 8개: backup/snapshot/mysqldump/mariabackup/xtrabackup 관련 활성 줄을 발견하지 못함. 읽기 실패 없음.
- `/var/backups`는 존재하며 직접 하위 항목 1개, 직접 하위 일반 파일 0개. 하위 디렉터리의 내용이나 백업 원문은 읽지 않음.
- 프로젝트 `deploy.sh`에서 백업 순환/만료 정책을 찾지 못함.
- 로컬 워크스페이스 `prod-db-backups`에 이전 배포 전 SQL 백업 파일이 존재함. 내용은 읽지 않음.

이는 **백업이 없다는 결론이 아니다**. 호스팅 업체의 외부 스냅샷, 다른 경로/명칭의 작업, 수동/로컬 사본은 위 조회에 포함되지 않는다. 가비아 상품의 백업 옵션·실제 보관 기간과 남은 수동 사본의 삭제 계획 확인이 필요하다. 7일 순환 설정을 실행하지 않았다.

## 사용자에게 다시 요청할 최소 정보

1. Sentry와 가비아 관리 화면에서 설정을 확인할 수 있는 방법. 사용자가 기술 설정을 직접 해석해서 답할 필요는 없다.
2. 기부금영수증을 실제로 홈택스 전자 발급하는지에 대한 회계 담당자의 답변. 공익단체 재지정 공고나 샘플 기부 파일은 다시 제출할 필요가 없다.

이 확인으로 모든 법정 기재 사항/국외 이전 근거/운영 파기가 검증된 것은 아니다. 확인 가능한 부분을 먼저 정리하여 요청 범위를 줄인 결과다.
