# 개인정보 보관 기간 검토 — 2026-09-06

사용자는 웹 검색을 통해 가능한 최대 보관 기간을 정하기를 요청했다. 아래는 확인한 법정 의무이며, 모든 개인정보에 적용할 수 있는 최대 허용기간 목록이 아니다. 적용 대상과 실제 파기 절차가 확정되지 않았으므로 공개 페이지에 현재 시행 중인 보관 기간으로 넣지 않았다. 기존 탈퇴·정리 코드는 변경하지 않았다.

| 기록 | 확인한 기준 | 적용 전 확인 |
| --- | --- | --- |
| 일반 회원 프로필·연락처·쪽지 | 처리 목적 달성 등으로 불필요해지면 지체 없이 파기. 다른 법령에 따른 보존 대상은 분리 저장·관리 | 법정 회계 증빙과 서비스 데이터를 구분해야 함. 회계 기록의 10년을 전체 회원 데이터에 적용하지 않음 |
| 기부자별 기부금영수증 발급명세 | 해당 의무 적용 시 발급일부터 5년. 법인세법은 전자기부금영수증 발급 시 해당 작성·보관 의무의 예외를 명시 | 장학회의 세법상 지위, 발급 주체, 홈택스 전자영수증 여부, 다른 장부 보존 의무와 중복 여부 |
| 공익법인등의 출연재산·공익사업 운용 장부와 중요한 증명서류 | 해당 과세기간 또는 사업연도 종료일부터 10년 | 장학회의 공익법인등 해당 여부, 실제 해당 증빙과 필수 개인정보 항목 |
| 방문 상세 기록·인증정보·차단된 메시지 | 기존 코드의 개별 정리 주기 적용. 방문 상세 기록은 90일 | 방문 통계 설정이 다른 보안 접속기록의 법정 의무 충족을 뜻하지 않음 |
| Sentry·백업·신고 증거 | 일률적인 법정 최대치를 확정하지 못함 | 실제 서비스 설정, 목적과 필요 기간, 접근권한, 파기 절차를 확인 |

같은 증빙에 복수의 보존 의무가 적용될 때는 각각의 기산일과 만료일을 계산하여 모두 충족해야 한다. 5년과 10년 중 숫자만 큰 것을 모든 기록에 일괄 적용하지 않는다. 분쟁·조사 등 개별 보존 근거가 있으면 해당 범위와 종료 조건을 별도로 기록한다.

## 공식 근거

- [개인정보 보호법 제21조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1027063705): 불필요한 개인정보 파기, 법정 보존 대상의 분리 저장·관리.
- [법인세법 제112조의2](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=02&joNo=0112&lsiSeq=280349&urlMode=lsScJoRltInfoR): 기부자별 영수증 발급명세 5년, 전자기부금영수증 예외.
- [상속세 및 증여세법 제51조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0051&lsiSeq=276123&urlMode=lsScJoRltInfoR), [국세청 공익단체 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=239037&mi=40647): 해당 장부·증명서류 10년 보존.
- [Apple 계정 삭제 안내](https://developer.apple.com/support/offering-account-deletion-in-your-app/): 계정 생성 지원 앱은 계정 및 관련 개인정보 삭제를 제공해야 하며, 법적으로 보존해야 하는 정보는 예외. 비활성화만으로는 부족하고 수동 삭제 절차도 실제로 수행한다면 허용된다.

공개 방침과 실제 구현은 일치해야 한다. ‘필요한 기록만 보존’으로 문구만 변경하는 방안은 적용하지 않았다. 이후 운영자는 앱에서 요청을 접수하고 담당자가 실제로 삭제하는 수동 처리 방식을 선택했다. 이 결정은 종전의 무기한 전체 보관 방침을 대체하는 목표이며, 아직 실제 데이터 삭제를 실행하거나 해당 처리 기능을 추가하지 않았다.

## 수동 삭제 운영 및 기간 제안

아래 운영 기간은 권장안이며, 아직 운영자가 확정한 기간이나 구현된 동작이 아니다. 법정 보존 대상은 적용 요건을 확인한 뒤 별도로 설정한다.

- 앱에서 인증된 삭제 요청을 영구 저장하고 접수 시각·접수번호를 제공한다. 이용자에게 별도의 이메일 발송을 요구하지 않는다. 개인정보 요청 담당자는 황제철이며, 운영 연락처는 `ghkdwp018@naver.com`이다. 직원 알림 자동 발송 여부는 아직 구현 결정 전이다.
- 일반 회원정보·프로필 사진·쪽지 등: 요청 후 가능한 즉시 삭제하고, 운영 목표는 3일 이내, 처리 결과 통지는 요청일부터 10일 이내로 제안한다. 10일을 추가 보관 유예기간으로 사용하지 않는다. 법정 보존으로 거절하는 범위는 근거·이유·이의제기 방법을 안내한다.
- 신고 원문·상세 설명: 처리 완료 후 최대 90일을 운영 검토안으로 제안한다. 더 이상 필요 없거나 관련 계정의 삭제 요청이 있으면 먼저 파기하며, 별도 법적 근거 없이 90일까지 무조건 남기지 않는다. 분쟁·수사 관련 보존은 개별 근거와 종료 조건을 관리한다.
- 운영 백업: 7일 순환 보관을 목표로 제안한다. 삭제 대상 백업의 만료/선택 삭제도 실제 삭제 일정에 포함해야 한다. 복원 시 삭제 내역을 다시 적용하고, 백업 정리가 끝나기 전에 전체 삭제 완료로 통지하지 않는다. 현 인프라의 지원 여부는 확인 전이다.
- Sentry: 비식별 진단 위주로 수집하고 30일 이하를 목표로 제안한다. 실제 요금제·데이터 종류별 기간 설정과 삭제 기능을 확인한 뒤 확정한다. 계정에 연결되는 진단 데이터는 삭제 요청 범위에 포함한다.
- 방문 상세 기록: 현재 코드의 90일을 유지하는 안. 더 짧게 유지해도 통계 목적을 달성할 수 있는지 검토한다. 개인정보취급자의 법정 접속기록과 구분한다.
- 관리자 등 개인정보취급자의 접속기록: 현행 기준상 1년 이상, 5만명 이상·고유식별정보/민감정보 처리 등 적용 요건에 해당하면 2년 이상. 각 요건을 확인하여 필요한 기간을 정하며 기존 구현이 이 의무를 충족한다고 간주하지 않는다.

추가 근거: [개인정보 보호법 시행령 제43조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0043&lsiSeq=283503&urlMode=lsScJoRltInfoR)의 정정·삭제 결과 10일 이내 통지, [개인정보의 안전성 확보조치 기준 제8조](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000281400&chrClsCd=010201)의 접속기록 보존 의무를 확인했다. 3일·7일·30일·90일 권장안은 이 법령이 일괄 지정한 기간이 아니다.
