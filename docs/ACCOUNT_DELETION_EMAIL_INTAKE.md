# 앱 없이 들어온 계정 삭제 요청 처리

Google Play는 앱을 설치하지 않고도 계정 삭제를 요청할 수 있는 웹 링크를 요구한다.
`https://daeilfoundation.or.kr/account-deletion` 페이지가 그 링크이며, 이메일로 요청하는 방법을 안내한다.
Play Console → 앱 콘텐츠 → 데이터 보안 → 계정 삭제 URL에 이 주소를 등록한다.

## 담당자 처리 순서

1. 개인정보 문의 메일함에서 `[대일외고 장학회 앱] 계정 삭제 요청` 메일을 확인한다.
2. 본인 확인: 보낸 주소가 회원 가입 이메일과 같은지, 이름·기수·학과·로그인 방법이 회원 정보와 맞는지 확인한다.
   맞지 않으면 접수하지 않고 가입 이메일로 다시 요청해 달라고 회신한다.
3. 관리자 → 회원 관리에서 회원을 찾아 회원 상세 주소(`/member/{번호}`)의 회원 번호를 확인한다.
4. 관리자 → 계정 삭제 요청 → **이메일 요청 대신 접수**에 회원 번호와 본인 확인 근거를 입력한다.
   근거에는 개인정보를 쓰지 않는다. 예: `가입 이메일 발신 확인, 2026-09-14 수신`.
5. 화면에 한 번만 표시되는 **처리 현황 확인번호**와 **취소 인증번호**를 회원에게 회신한다.
   이 화면을 벗어나면 다시 볼 수 없다. 메일 외의 곳에 번호를 남기지 않는다.

## 접수 후 동작

- 앱에서 요청한 것과 똑같이 계정 이용이 즉시 중지되고, 회원의 모든 로그인 세션이 종료된다.
- 예약 시각(현재 요청 후 7일)이 지나면 자동 처리되며, 그 전에는 회원이 확인번호와 취소 인증번호로 직접 취소할 수 있다.
- 누가 어떤 근거로 대신 접수했는지는 `ALUMNI_ACCOUNT_DELETION_INTAKE`에 기록되고, 요청 기록과 함께 보존 기간 뒤 삭제된다.
- 루트 관리자만 접수할 수 있고, 자기 계정은 대신 접수할 수 없다. 탈퇴 접수가 중지된 상태에서는 거부된다.
