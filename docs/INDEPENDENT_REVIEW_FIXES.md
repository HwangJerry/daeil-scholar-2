## DB 적용 영향

새 063은 기존 ALUMNI_DONATION_RETENTION에 SOURCE_FINGERPRINT 열만 추가한다.
기존 기부 원본·검토 행·암호화 보관소를 지우거나 과거 데이터 정리를 실행하지 않는다.
지문 없는 과거 검토는 자동 삭제에 사용할 수 없으므로 해당 원본을 다시 검토해야 한다.
관리자가 이후 기부를 수정하면 해당 주문의 기존 검토만 같은 트랜잭션에서 무효화한다.
외부 전달 정보 갱신 시에도 최초 만료일은 연장하지 않는다.

`cmd/donation-retention -inspect-order ID`는 검토할 원본 지문만 조회한다.
검토 JSON에는 그 원본의 sourceFingerprint를 포함해야 한다. dry-run은 형식만 검증하고,
실제 저장에서는 현재 원본과 다시 대조한다. 상세 절차는 AUTOMATIC_ACCOUNT_ERASURE.md 참고.

## 남은 운영 확인

수정 전 후보는 계속 HOLD 상태다. 새 후보는 준비만 하며 배포·마이그레이션·활성화는 실행하지 않는다.
운영 권한, 백업/DB 변환 시간 및 복구 절차, 소셜 제공자 철회와 일회용 계정의 실제 탈퇴,
외부 저장소/영수증 업무 증빙은 기존 운영 확인 범위로 남는다.
